# Nossa Senhora Aparecida

Página única sobre a Padroeira do Brasil, com a história e a devoção reunidas em um só lugar.

**[Abrir o site](https://uaimarquez.github.io/NossaSenhoraAparecida/)**

![Página inicial do site Nossa Senhora Aparecida](https://uaimarquez.github.io/assets/aparecida.jpg)

## O que tem no site

- A história da imagem sagrada
- A cronologia da devoção
- A Basílica de Aparecida
- Curiosidades sobre a padroeira
- Orações

## Como foi feito

Todo o HTML, o CSS e o JavaScript ficam no `index.html`, sem frameworks. As seções aparecem durante a rolagem com `IntersectionObserver`, e o layout se adapta a telas pequenas.

## Como rodar

Baixe o repositório e abra o `index.html` no navegador. Não é preciso instalar nada.
